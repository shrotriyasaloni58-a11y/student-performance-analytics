# Student Performance Analytics System

## About the Project

The Student Performance Analytics System is a Python project I built to understand and analyze student marks. It helps calculate averages and grades, compare the performance of different subjects and departments, and identify students who may need extra academic support.The project uses sample student data for demonstration and learning purposes.

I used Pandas and NumPy for working with the data and Matplotlib to create visual charts.


## What It Can Do

- Calculate each student's total and average marks.
- Assign grades based on average marks.
- Check whether students have passed or failed.
- Find the top 5 performing students.
- Calculate the overall class average and other statistics.
- Compare average marks across different subjects and departments.
- Identify students who may need help improving their performance.
- Check the dataset for missing values and duplicate records.
- Save the analyzed data to a new CSV file.
- Display subject-wise average marks in a bar chart.


## Tools and Technologies

- **Python** – for writing the program.
- **Pandas** – for organizing, filtering, and analyzing student data.
- **NumPy** – for numerical computing.
- **Matplotlib** – for creating charts and visualizing results.
- **CSV** – for storing the student dataset and analysis report.


## How to Run the Project

1. Install Python on your computer.
2. Install the required libraries by running this command in the terminal:

   `py -m pip install pandas numpy matplotlib`

3. Keep `main.py` and `students.csv` in the same project folder.
4. Open the terminal in that folder and run:

   `py main.py`
